# TCM2 报告规则

## 标题
```text
📊 **战队名 阶段（总人数）| 日期 时间窗口 | 第N周**
```

## 每关格式
```text
**阶段#第X关卡（百分比）：** ✅N 🔄N ❌N
  🔄 闯关中：名字(英文)、...
  ❌ 未闯关：名字(英文)、...
```

## 姓名规则
1. 已完成（✅）不列名字
2. 每阶段首关：无条件列全部 🔄 + ❌ 名字
3. 后续关：
   - 上一关 ❌ < 10 → 列当前关卡 🔄 + ❌ 名字（去重）
   - 上一关 ❌ >= 10 → 只报数
4. 名字格式：`中文名(英文名)`
5. 多人用 `、` 分隔
6. 大侠/少侠 与 书童 为独立阶段

## 关卡号规则
保留页面原始阿拉伯数字形式，例如：
- `第35关卡`
- 不要改成中文数字

## 百分比规则
保留页面原值：
- 页面是整数，就报整数
- 页面是小数，就保留该小数

## 周数规则
必须读取当前激活周：
```javascript
document.querySelector('.week-item.is-active .el-radio-button__inner')?.textContent?.trim()
```
再提取其中的 `第N周`。

## 活跃学生
格式：
```text
### 🟢 活跃学生
| 学生 | 关卡 | 状态 | 更新时间 |
|------|------|------|----------|
```

判断规则：
- 基于 `结束闯关时间`
- 默认窗口双锚点：12:00 / 17:00
- 去重时优先保留：
  1. 闯关中
  2. 更高关卡
  3. 更晚更新时间
